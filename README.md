# Candy Distributor Analytics Dashboard

Repo ini berisi file Power BI (.pbix) dan dataset CSV untuk analisis distribusi permen.

## Struktur Folder
📂 data → berisi file CSV sumber  
📄 dashboard.pbix → file Power BI utama  
📄 README.md → dokumentasi proyek

## Cara Pakai
1. Download repo ini (ZIP atau git clone).
2. Pastikan file `.pbix` dan folder `data` ada di lokasi yang sama.
3. Buka `dashboard.pbix` di Power BI Desktop.
4. Klik **Refresh** untuk memuat ulang data dari CSV.
