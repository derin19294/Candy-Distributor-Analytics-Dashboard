# Candy Distributor Analytics Dashboard

This repository contains a Power BI (.pbix) file and CSV dataset for candy distribution analysis.

## Folder Structure

📂 `data` → contains the source CSV files were obtained from **Maven Analytics**
📄 `dashboard.pbix` → main Power BI dashboard file
📄 `Build portofolio candy distributor` → steps documentation to build candy distributor analytics dashboard
📄 `README.md` 

## How to Use

1. Download this repository (ZIP or git clone).
2. Make sure the `.pbix` file and the `data` folder are in the same location.
3. Open `dashboard.pbix` in Power BI Desktop.
4. Click **Refresh** to reload the data from the CSV files.
